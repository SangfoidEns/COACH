# GROK EXCLUSIVE ARTIFACTS — Metalist Stuttgart

Артефакти цієї серії створює **тільки Grok**. Вони унікальні для клубу Metalist Stuttgart і не існують в інших продуктах.

## Як замовити новий артефакт

Напиши в чат у такому форматі:

```
АРТЕФАКТ:
назва: ...
для кого / привід: ...
настрій: (кібер / золото / героїка / ніжність / technoir ...)
емодзі-якір (опційно): ...
фото/референс (опційно)
```

## Що робить Grok

1. Унікальний `id` + `special` class
2. Опис + momentHint українською
3. Анімація CSS (5 років уперед, glass/hologram/pulse)
4. Запис у `CoachTools.GIFT_CATALOG`
5. ZIP-оновлення
